# AGENTS.md — evidence-grounded-re (EGRE)

Research-engineering project: an LLM reverse-engineering agent whose claims are audited
against the evidence it actually retrieved. Read this file fully, then follow docs/LOOP.md.

## Read order at the start of every session
1. docs/STATUS.md  — where we are; contains `loop_signal`.
2. docs/TASKS.md   — pick the first `todo` task whose `depends` are all `done`.
   PROTOTYPE MODE: scope and interfaces are in docs/PROTOTYPE.md (read it for every task); ignore stage lists in other docs.
3. Only the docs that task names (ARCHITECTURE, CLAIM_TAXONOMY, ...). Do not read everything.

## Commands
- Setup:   `pip install -e ".[dev]"`
- Verify:  `./scripts/verify.sh`   (must pass before any task is marked done)
- Full:    `./scripts/verify.sh --full`  (adds `toolchain`-marked tests; needs Ghidra/radare2/clang on this Mac)
- Env:     `./scripts/check_env.sh`
- Tests:   `python -m pytest -q`

## Non-negotiable rules (full list: docs/GUARDRAILS.md)
1. One task per iteration. Never start a second task.
2. A task is done only when its `acceptance` command AND `./scripts/verify.sh` pass.
   Record the result summary in docs/PROGRESS.md.
3. Never edit, delete, skip or weaken a test to make it pass. If a test is wrong, stop and
   record it in docs/DECISIONS.md.
4. Never edit human-owned files (scripts/protected_paths.txt). Propose changes in docs/DECISIONS.md.
5. Verdicts are deterministic. No LLM call may decide claim status, experiment outcome or truth.
6. Runtime code (src/egre/{agent,mediator,ledger,claims,contracts,runner,controller,report})
   must never import egre.corpus or egre.evaluation. tests/test_boundaries.py enforces this.
7. No real LLM/API calls unless the task says `spend: approved`. Use the fake/replay client.
8. No malware, no exploit development. Corpus programs are benign and synthetic.
9. After 3 failed attempts on one task: mark it `blocked`, explain in docs/PROGRESS.md,
   set `loop_signal: STOP_BLOCKED` in docs/STATUS.md.
   Network, install or missing-tool failures are environmental: set `loop_signal: STOP_HUMAN` instead.
10. Platform is native macOS arm64 (Mach-O corpus). No Docker, no Linux-only tools (gdb, strace, ltrace),
    no sudo, no system-wide installs, no edits to shell profiles. Need a tool? STOP_HUMAN.

## Layout
src/egre/<component>/ mirrors docs/ARCHITECTURE.md; tests/<component>/ mirrors src.
docs/ = specs + loop state. corpus/ = generated programs. runs/ = experiment output (gitignored).

## Where things go
- Progress log (append-only): docs/PROGRESS.md
- Snapshot (overwrite): docs/STATUS.md
- Decisions / spec questions: docs/DECISIONS.md
- Do not edit this file. Propose additions in docs/DECISIONS.md.
